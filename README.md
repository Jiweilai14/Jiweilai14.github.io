# 一天一件

睡前写三件事。不打卡，不评分，数据只留在你自己的设备上。

[**打开使用**](https://jiweilai14.github.io/) · [装到主屏](#装到主屏) · [许可](#许可)

## 这是什么

一个睡前花三分钟写点东西的网页。不是日记，不是待办清单，不会催你连续打卡。

三块，各管一件事：

| 区块 | 写什么 | 写完怎样 |
|---|---|---|
| **倒出来** | 没做完的、没回的消息、说不清的担心，一行一件 | 点「粉碎」，文字当场消失，只留「碎了几件」这个数字 |
| **做成的事** | 今天做到了什么。多小都算 | 存进记录 |
| **好受的瞬间** | 今天哪个瞬间让你好受了一点 | 存进记录 |

两块记录区每天会给一句不同的起头（比如「今天我做了一件很小的事：」），点一下就能填进输入框；写不下去就按「换一句」，或者收起它。

## 几个刻意的选择

- **烦恼不存档。** 存档会变成一份待办清单，每次翻到都在提醒你还没解决。这里要的是「我放下了」这个动作，不是留证据。
- **只写已经发生的事。** 不写目标、不写计划。「我能行」是从「我做到过」里长出来的，不是从许愿里。
- **没有打卡、没有连续天数、没有红色的叉。** 断一天不扣分，空白就是空白。

应用内的「为什么这么写」页有完整说明和引用的研究出处——想较真可以去那儿看。

## 数据与隐私

- 所有内容只存在你浏览器的 localStorage，**不上传任何服务器**。没有账号、没有统计埋点、没有第三方请求——页面零外部依赖，打开源码搜 `http` 就能验证。
- 烦恼的文字**不会落盘**：粉碎只留下「条数」这个数字。
- 换设备、清缓存、用无痕模式都会丢数据 → 用「我的 → 导出备份」存一份 JSON。写到第 7 条时会提醒一次。
- 数据格式当前是 v3，从旧版本打开会自动迁移。
- 隐私模式、禁用存储、或直接双击 `file://` 打开时可能存不住，页面会给出提示。

## 功能

| 功能 | 说明 |
|---|---|
| 三个写作区 | 引导句每日轮换，可换、可收起 |
| 粉碎 | 逐行下落消失的动画，文字当场清空 |
| 记录 | 按「做成 / 好受 / 全部」筛选，支持关键词搜索 |
| 回顾 | 自动捞出「一个月前的今天」「去年的今天」 |
| 我的 | 4 个计数 + 最近四周的记录格 |
| 我现在很难受 | 随机调出你以前（3 天前之前）写过的东西 |
| 导出 / 导入 | JSON 备份，换手机不丢 |
| 深色模式 | 跟随系统，含两份 manifest 保证状态栏配色正确 |
| 离线 | Service Worker 预缓存，断网可开 |
| 支持 | 赞赏码入口（链接加 `?nosupport=1` 可隐藏，适合发给熟人） |

## 技术

一个 HTML 文件，约 1000 行。零构建、零依赖、零后端。

| 文件 | 作用 |
|---|---|
| `index.html` | 全部界面、样式、逻辑 |
| `sw.js` | 离线缓存。导航请求网络优先（保证拿得到新版），静态资源缓存优先 |
| `manifest.webmanifest` | 浅色主题清单 |
| `manifest-dark.webmanifest` | 深色主题清单（系统栏主题色只能写死一个，所以分两份按系统切换） |
| `icons/` | 图标，由 `make_icons.py` 生成 |
| `screenshots/` | 上面那几张图 |

没有框架、没有打包器。改一行样式，刷新就能看到结果。

## 本地运行

```bash
python -m http.server 8000
# 打开 http://127.0.0.1:8000
```

不要直接双击 `file://` 打开——多数浏览器会限制 localStorage，Service Worker 也不工作。

## 部署到 GitHub Pages

本目录内容就是站点根目录。推到仓库后：Settings → Pages → Deploy from a branch → 选分支和 `/ (root)`。

`manifest` 和 `sw.js` 全部使用相对路径，所以放在根目录或子目录都能跑。

## 已知限制

- 单设备单浏览器，**没有云同步，也不打算做**——那需要服务器，和「数据只在你自己手里」直接冲突。
- 清缓存或换设备必须手动导出导入。
- 没有做完整的无障碍适配。部分次要文字的对比度按 WCAG 校准过，但整体不算达标。
- 不是医疗工具，见下方免责声明。
